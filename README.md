# pycogent

Set of Python tools for COGENT by Dominic Power, based on scripts shared by Vasily Geyko


## Check out from github:
git clone https://github.com/plasdom/pycogent
or
git clone ssh://git@github.com/plasdom/pycogent


## Install:
Set up pycogent as a package by running the following command inside the directory containing `setup.py`:

`pip install --editable . --user`
